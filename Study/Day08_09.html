Days 8 and 9: Training deep networks, sequences and transformers

Why depth matters, how to make very deep networks train, and how RNNs and LSTMs handle sequences. The clickstream part of sample question 1d is answered at the end of the sequence section.

1. Why depth matters

The universal approximation theorem says a network with one hidden layer can, in principle, approximate any continuous function. But it gives no practical way to find those weights, and in practice depth, not width, is what made image recognition work.

The notes show an experiment on AlexNet (8 layers, 60 million parameters, 650,000 neurons). Top-5 accuracy is the share of images where the true class is among the model's 5 highest guesses (original: 81.9%).

3. Training very deep networks: the problems and the fixes

3.1 Vanishing gradients

Backpropagation multiplies many derivatives of the activation function together as the error travels back. If each is small, the product shrinks towards zero, so the early layers (the feature extractors) barely learn.

Fix 1, activation: use ReLU. For active units its derivative is exactly 1, so it adds no shrinking factor. (Sigmoid and tanh saturate near their ends where the derivative is almost zero.)

3.2 Weight initialisation

  • Never start all weights at 0 (all units learn identically and nothing breaks symmetry).
  • Too small: the signal shrinks layer by layer, neurons go "dead". Too large: signals blow up, neurons saturate.
  • Xavier (Glorot): designed for sigmoid and tanh. Variance scaled by the number of inputs (about 1/n). Keras default for weights, with zero biases.
  • He: designed for ReLU. Normal distribution with mean 0 and variance 2/n (n = inputs to the neuron, the "fan-in"). Use kernel_initializer='he_normal'.

3.4 Optimiser, learning rate and batch size

  • Optimiser = rule for updating weights. Plain SGD; Adam and RMSprop adapt the step per weight (they keep running averages of the gradient and squared gradient). Adam with learning rate 0.001 is a common start.
  • Learning rate: too big converges to a poor point or diverges, too small is slow. Use a scheduler to lower it as training proceeds.
  • Batch size: large = faster but accuracy may suffer and needs GPU memory. Small = noisier, with a mild regularising effect.

3.5 Very deep networks: degradation and ResNet

Even with ReLU, good initialisation and batch norm, a much deeper plain network can show higher training error than a shallower one. This is degradation, not overfitting (in overfitting, training error is low and test error is high). In theory extra layers could just copy their input (identity mapping), but plain layers find that hard to learn.

ResNet fix: let a block learn only the residual F(x) and add the input back with a skip connection: H(x) = F(x) + x. If the best thing is to do nothing, F(x) just has to go to 0, which is much easier than learning the identity. The skip connection also gives the gradient a short path back, helping early layers learn.

4. Sequences: RNN and LSTM (sample Q1d)

Normal networks treat inputs as independent. In sequences (words, sensor readings, clickstreams) what came before matters. A recurrent neural network (RNN) reads one element at a time and carries a hidden state forward, so the output at a step depends on the earlier steps.

CNNRNN
DataSpatial (images, video frames)Sequential or temporal (text, time series)
Input sizeFixedCan vary in length
ConnectivityLocal patterns through convolutionUses earlier time steps through feedback

Preparing sequence data: "make steps"

You do not feed the whole series. You cut it into fixed-length windows (each window = time steps), moving forward by a chosen distance (stride). For the series 0, 1, 1, 3, 2, 2, 4, 5, 4, 7, 8, 8, 9, window length 4 and distance 3 gives:

[0, 1, 1, 3] [3, 2, 2, 4] [4, 5, 4, 7] [7, 8, 8, 9]

Each window is one sample of shape (time steps, features). For prediction you also pair each window with a target: the next value, or a label for the window. Splitting into train and test must respect time order, not random rows.

Sizes and parameters

Input D features per step, hidden size H: W is H x D, U is H x H, b has H values SimpleRNN parameters = H·(D + H) + H e.g. D=64, H=32: 32·96 + 32 = 3,104 Output layer: Dense(1) on 32 hidden = 32 + 1 = 33

The problem: long memory, and the LSTM

Unrolled over many steps, an RNN is like a very deep network, so it has the vanishing gradient problem and forgets distant context. The LSTM (long short-term memory) adds a cell state (a "conveyor belt" of memory) controlled by gates:

  • Forget gate: how much of the old memory to keep.
  • Input gate: how much new information to write.
  • Output gate: how much of the memory to expose as the output.

Each gate and the candidate memory has its own weights, so an LSTM has four times the parameters of a simple RNN of the same size:

LSTM parameters = 4 × ( H·(D + H) + H ) e.g. D=64, H=32: 4 × 3,104 = 12,416 Stacked LSTM: use return_sequences=True on all but the last LSTM so the next layer gets the whole sequence. (3 steps, 5 features) → LSTM 7: 4·(7·12 + 7) = 364, output (3, 7) → LSTM 9: 4·(9·16 + 9) = 612, output (9) → Dense 1: 10

Output layer decides the task: regression = Dense(1) linear + MSE. Binary class = Dense(1) sigmoid + binary cross-entropy. Multi-class = Dense(k) softmax + categorical cross-entropy.

Sample Q1d model answer (clickstream)

  • Technique: an LSTM (or GRU), because the order of pages, the time on each and the path matter.
  • Training data structure: each visitor session is one sequence of events. Each step has features such as page category, time spent, how the user arrived, and where they went next (one-hot or embedding for categories, scaled numbers for times). The label is whether the session ended in a purchase (many-to-one). Alternatively predict the next page.
  • Pre-processing: sort events by time, cut or pad sessions to a fixed length (with masking) or use windows, scale numeric inputs, handle class imbalance (class weights, oversampling), and split train and test by session (and ideally by time).
  • Combining with earlier models: feed the LSTM's purchase probability (or its final hidden state) as an extra feature into the tabular model from part (b), or average and stack the predictions of the LSTM and the tabular models. This is a hybrid or ensemble: the sequence model adds browsing behaviour that the aggregated page-view features miss.

5. Transformers (Day 9, short)

Transformers replace recurrence with self-attention: every token looks at every other token directly, so long-range links are easy and training runs in parallel.

  • Query, key, value: each token makes a query (what I look for), a key (what I offer) and a value (the information). Attention weights = softmax(Q·Kᵀ / √d_k), and the output is the weighted sum of the values.
  • Multi-head attention: several attention heads with different weights capture different relationships (for example subject, phrase structure).
  • Positional encoding: attention has no built-in order, so position information is added to the token embeddings.
  • Encoder block: self-attention, Add and Norm, feed-forward layer, Add and Norm. Decoder block: masked self-attention (a token cannot see the future), cross-attention to the encoder output, feed-forward.
  • Variants: encoder-only (BERT) for understanding, decoder-only (GPT) for generation, encoder-decoder for translation.

6. Practice questions (exam style)

Question A: sequence windows and parameters

A sensor gives 2, 4, 6, 8, 10, 12, 14. (a) Make windows of length 3 with distance 2. (b) An LSTM with 10 hidden units reads inputs with 2 features per step. How many parameters does it have? (c) Why would a plain RNN struggle on a sequence of 500 steps? (4 marks)

Show the worked answer

(a) [2, 4, 6], [6, 8, 10], [10, 12, 14].

(b) 4 × (H·(D + H) + H) = 4 × (10·12 + 10) = 4 × 130 = 520.

(c) Over 500 steps the gradient is multiplied by many small factors (vanishing gradient), so the network cannot link far-apart events. An LSTM's gated cell state, or a transformer, handles long dependencies better.

Question B: diagnose a deep network

A 40-layer plain CNN with sigmoid activations has training accuracy 55% and validation accuracy 54%. A 10-layer version reaches 75% on training data. (a) What is wrong and is it overfitting? (b) Give three fixes. (4 marks)

Show the worked answer

(a) Not overfitting, because training accuracy is low and the validation score is about the same. The deeper net is trained worse than the shallow one, which points to vanishing gradients (sigmoid, 40 layers) and degradation.

(b) Switch to ReLU with He initialisation; add batch normalisation; add residual (skip) connections (ResNet). Also tune the learning rate or use Adam.

Quick recall questions
  1. What is the largest derivative of a sigmoid?
  2. In dropout, is anything dropped at test time?
  3. What does a ResNet block learn?
  4. Which Keras style do you need for two inputs?
  5. How many times more parameters does an LSTM have than a SimpleRNN of the same size?

Answers: (1) 0.25. (2) No, only during training. (3) The residual F(x) = H(x) − x, output is F(x) + x. (4) The Functional API. (5) Four times.
