From the perceptron to convolutional networks. This covers the layer-by-layer shape and parameter counting you need for sample question 2a, with that question worked through in full.

1. The story of deep learning (and why it matters for the exam)

1943McCulloch-Pitts neuron. 0/1 inputs, fixed weights, no learning.
1958Perceptron (Rosenblatt). Real inputs, learns weights from data.
1969Minsky and Papert show one perceptron cannot do XOR. First AI winter.
1986Backpropagation (Rumelhart, Hinton, Williams) trains multilayer networks.
Late 80sDeep nets will not train. SVMs and random forests take over. Second winter.
2012AlexNet wins ImageNet: 15.3% top-5 error against 26.2% for the runner-up.

Why backpropagation failed before 2012: labelled datasets were thousands of times too small, computers were millions of times slower, weights were initialised badly (all 0 or all 1), and the wrong activation function was used (sigmoid and tanh squash gradients to zero).

What AlexNet changed: ReLU activation, dropout, GPU training (about 20x faster), and a huge labelled dataset (ImageNet: 1.2 million images, 1,000 classes). Its structure was similar to the 1989 LeNet. The recipe is lots of data + deep convolutional network + backprop on GPU.

The notes' three problem types for deep learning: Identify (classify, detect, segment), Create (generative AI: text, images, audio, video), Act (deep reinforcement learning: robots, games, vehicles).

2. One neuron and the perceptron

net = w0 + w1·x1 + w2·x2 + ... + wn·xn (w0 is the bias weight, with input +1) output = f(net) f = activation function hard-limit: f = 0 if net ≤ 0, else 1 sigmoid: f = 1 / (1 + e^(−net))

Worked example (from the notes). Inputs x1 = 1, x2 = 0. With w0 = −3, w1 = 2, w2 = 6: net = −3 + 2 + 0 = −1, so y = 0. With w0 = −2, w1 = 3, w2 = 5: net = −2 + 3 = 1, so y = 1. Same inputs, different weights, different output. That is exactly why a network can learn: change the weights to reduce the gap between target and output.

Perceptron learning rule

Δwi = η · (T − O) · xi wi(new) = wi(old) + Δwi T = target, O = output, η = learning rate (0 to 1)
  • Output right: no change.
  • Output 0 but should be 1: increase weights on active inputs.
  • Output 1 but should be 0: decrease weights on active inputs.

Worked example. Start with w0 = −0.5, w1 = −1, w2 = 1.5, η = 0.5. The pattern (x1, x2) = (0, 1), class B (target 0), gives net = −0.5 + 0 + 1.5 = 1.0 > 0, so output is 1: an error. Update (inputs are x0 = 1, x1 = 0, x2 = 1):

Δw0 = 0.5 × (0 − 1) × 1 = −0.5 → w0 = −1 Δw1 = 0.5 × (0 − 1) × 0 = 0 → w1 = −1 (input was 0, so no change) Δw2 = 0.5 × (0 − 1) × 1 = −0.5 → w2 = 1 New net for (0, 1) = −1 + 0 + 1 = 0 → output 0. Correct.

Linear separability and XOR

A single perceptron draws one straight line (in 2D; a hyperplane in general): w0 + w1·x1 + w2·x2 = 0, which is x2 = −(w1/w2)·x1 − (w0/w2). It can only solve problems where one line separates the classes (linearly separable). The convergence theorem says it learns a solution if and only if one exists.

3. The multilayer perceptron and backpropagation

An MLP has an input layer, one or more hidden layers and an output layer, with every node connected to every node in the next layer (fully connected, feedforward). The hidden layers give the non-linearity: nodes in the first hidden layer each draw a line (hyperplane), the next layer combines lines into convex regions, and a further layer can build concave regions.

Training loop

  1. Initialise weights to small random values (never all zero).
  2. Forward pass: compute the output.
  3. Compute the error against the target with a loss function.
  4. Backward pass (backpropagation): pass the error back through the layers to see how each weight contributed.
  5. Update each weight by gradient descent. Repeat until the error is small enough or you hit a stopping rule.
Sigmoid units, error term δ, learning rate η: output unit j: δj = Oj · (1 − Oj) · (Tj − Oj) hidden unit j: δj = Oj · (1 − Oj) · Σk δk · wkj (k = units j feeds into) weight change: Δwji = η · δj · Oi

Worked numbers from the XOR example in the notes (learning rate 0.3, output O1 = 0.508, target 0):

δ1 = 0.508 × (1 − 0.508) × (0 − 0.508) = −0.127 Δw13 = 0.3 × (−0.127) × 1 = −0.038 (weight is pushed down, which lowers the output)

Training choices to know

TopicWhat to say
Loss functionMSE for numeric targets. Cross-entropy for classification (preferred).
Gradient descent typesBatch: all examples then update. Stochastic: one example at a time (noisy). Mini-batch: n at a time (the usual choice).
Learning rateStep size. Not constant for best results (decay or schedule).
MomentumAdds a fraction of the previous weight change: smooths the descent and helps skip shallow dips.

Ways to prevent itMore data, random order of examples, early stopping, noise injection, prune nodes, L2 regularisation (weight decay), dropout.

Why we need a non-linear activation: without it, a stack of layers collapses to one linear model. ReLU also gives sparse outputs (many exact zeros), so only important neurons contribute.

5. Convolutional neural networks (CNN)

A dense network on a 128 x 128 x 3 image has 49,152 inputs per neuron, which is far too many weights. A convolution slides a small filter (kernel) over the image and reuses the same few weights everywhere. That gives fewer parameters and detects a pattern wherever it appears.

Early layers find simple things (edges, brightness changes). Deeper layers combine them into shapes, parts and objects. You do not choose the filter values (training does). You choose only the size and number of filters.

First output cell: top-left 3 x 3 window is [1 2 0; 0 1 3; 2 1 0]. Only the kernel's 1-positions count (the four corners and the centre): top-left 1, top-right 0, centre 1, bottom-left 2, bottom-right 0, so 1 + 0 + 1 + 2 + 0 = 4. Move the window one step right for 9, one step down for 6, and both for 5.

Size formulas (learn these)

Output size (rows) = floor( (W − F + 2P) / S ) + 1 W = input size, F = filter size, P = padding, S = stride Conv parameters = ( Fr × Fc × Cin + 1 ) × Cout (the +1 is the bias, one per filter) Dense parameters = inputs × outputs + outputs Pooling and Flatten parameters = 0
  • Padding "same": output size = input size (stride 1). "valid": no padding, output shrinks.
  • Stride: how far the window moves. Stride 2 roughly halves the size.
  • Multi-channel input: each filter spans all input channels, products are summed across channels into one output channel. Number of filters = number of output channels.
  • Max pooling 2 x 2, stride 2: halves height and width, keeps the largest value in each window, channels unchanged, no parameters. It reduces size and overfitting and makes the network tolerant to small shifts.
  • Dropout: randomly switches off a fraction (rate p, often 0.2 to 0.5) of units during training only to regularise.

The first Dense layer alone holds 2.41 million of 2.58 million parameters, about 93%.

(i) Do you agree that the last layers are poorly designed? Yes, for these reasons

  • Parameter explosion: Flatten (9,408) into Dense 256 creates 93% of all weights, far more than 5,000 images can support. This invites overfitting.
  • One 918-way softmax: it treats "Samsung-kettle-high" and "Samsung-kettle-low" as unrelated classes, so evidence about "Samsung" or "kettle" is not shared. With about 5 images per class the classifier is badly under-supplied, and uneven categories make it worse.
  • No regularisation (no dropout, batch normalisation or augmentation) and the activation and loss functions are not stated.

(ii) and (iii) A better model, and why

ChangeReason and advantage
Three softmax heads (18, 17, 3) instead of one 918-way headEach head sees far more examples per class: about 5,000/18 = 280 per brand, 5,000/17 = 290 per type, 5,000/3 = 1,670 per value, against about 5 per combination. Knowledge about a brand is shared across all its types. Can still recover all 918 bins.
Global average pooling instead of FlattenCuts the 9,408 inputs of the first dense layer to 48, removing the parameter explosion, and makes the model less sensitive to where an object sits.
Dropout and batch normalisationRegularise and speed training.
Data augmentation (flips, rotations, crops, brightness) and class weightsCreate variety from 5,000 images and offset the uneven category counts.
Transfer learning (optional)Start from a pretrained backbone and fine-tune, which works well with little data.

If you keep Flatten and only split the output into three heads, the total becomes 2,578,982 − 118,422 + 4,902 = 2,465,462 (only 4% fewer). That is why the global-pooling change is the important one. State your architecture so the number is traceable.

  • Activations: ReLU in all hidden layers (conv and dense). Softmax at each of the three outputs, because each head picks one class out of several.
  • Loss: categorical cross-entropy for each head, summed (optionally weighted). If one image could have several labels at once, use sigmoid outputs and binary cross-entropy instead.
Exam angleFor a network-critique question: (1) compute shapes and parameters and point at where the weights sit, (2) relate to data size (5,000 images against 918 classes), (3) propose specific changes with a reason each, (4) recompute parameters, (5) give activation and loss. Showing the parameter table is where many marks come from.

7. Practice questions (exam style)

Question A: shapes and parameters

Input 64 x 64 x 1. Conv 5 x 5, 8 filters, no padding; MaxPool 2 x 2; Conv 3 x 3, 16 filters, no padding; MaxPool 2 x 2; Flatten; Dense 64 (ReLU); Dense 5 (softmax). (a) Give the output shape after each layer. (b) Give the number of parameters in each layer and the total. (c) Which layer has most parameters and what is the risk? (5 marks)

Show the worked answer

(a) Conv1: (64 − 5) + 1 = 60, so 60 x 60 x 8. Pool: 30 x 30 x 8. Conv2: 30 − 3 + 1 = 28, so 28 x 28 x 16. Pool: 14 x 14 x 16. Flatten: 14·14·16 = 3,136. Dense: 64. Output: 5.

(b) Conv1: (5·5·1 + 1)·8 = 208. Conv2: (3·3·8 + 1)·16 = 73·16 = 1,168. Dense 64: 3,136·64 + 64 = 200,768. Output: 64·5 + 5 = 325. Pooling and Flatten: 0. Total 202,469.

(c) The Dense 64 layer (about 200,000 of 202,000, roughly 99%). With limited data it can overfit. Reduce it with global average pooling, fewer units, dropout or L2.

Question B: perceptron update

A perceptron has w0 = 0, w1 = 1, w2 = −1, learning rate 0.5, and outputs 1 if net > 0, else 0. The pattern (x1, x2) = (1, 1) has target 1. (a) What is the output? (b) Apply one update. (c) Is the pattern now correct? (3 marks)

Show the worked answer

(a) net = 0 + 1·1 + (−1)·1 = 0, which is not greater than 0, so the output is 0. Target is 1, so there is an error.

(b) T − O = 1. Δw0 = 0.5·1·1 = 0.5, Δw1 = 0.5·1·1 = 0.5, Δw2 = 0.5·1·1 = 0.5. New weights: w0 = 0.5, w1 = 1.5, w2 = −0.5.

(c) net = 0.5 + 1.5 − 0.5 = 1.5 > 0, so the output is 1. Correct.

Quick recall questions
  1. Why can a single perceptron not solve XOR?
  2. Give the output size for a 28 x 28 input, 5 x 5 filter, stride 1, no padding.
  3. How many parameters in a conv layer with 3 x 3 filters, 16 input channels and 32 filters?
  4. Which activation do you use in the output layer for a 10-class problem?
  5. Name three ways to reduce overfitting in a neural network.

Answers: (1) XOR is not linearly separable and one perceptron draws one line. (2) 24 x 24. (3) (3·3·16 + 1)·32 = 145·32 = 4,640. (4) Softmax. (5) Dropout, early stopping, L2 regularisation, more data or augmentation, fewer nodes.
